# Compact U(1) Lattice Gauge Theory — Phase 2 Reference

The first genuinely-gauge model in the phase plan. Link variables encode an
Abelian gauge field on the lattice; the Wilson plaquette action discretizes
the Maxwell action `S = (1/4) ∫ F_μν F^μν`.

## Link variables and the Wilson plaquette action

To each directed lattice link `(x, x + ê_μ)` we attach a phase
`θ_μ(x) ∈ ℝ`. The associated group element is
`U_μ(x) = exp(i θ_μ(x)) ∈ U(1)`. Storing the phase rather than the complex
number halves memory and lets every observable use `cos / sin` directly.

The smallest closed loop on the lattice is the **plaquette** — an oriented
unit square in the (μ, ν) plane, traced `x → x+ê_μ → x+ê_μ+ê_ν → x+ê_ν → x`.
Its accumulated phase is

```
θ_□(x; μ, ν) = θ_μ(x) + θ_ν(x + ê_μ) − θ_μ(x + ê_ν) − θ_ν(x).
```

The Wilson action sums one contribution per oriented plaquette (each
(μ, ν) pair with μ < ν, each starting corner once):

```
S[θ] = β Σ_□ (1 − cos θ_□).
```

For weak coupling (large β) this reproduces the continuum Maxwell action
with `g² = 1 / β`; the lattice expansion `1 − cos x ≈ x²/2 − x⁴/24 + …` is
the analog of the Wilson-fermion improvement story.

## Gauge invariance

The action is invariant under the local gauge transformation
`θ_μ(x) → θ_μ(x) + α(x + ê_μ) − α(x)` for any site-field α(x). The
test-suite check `U12D.ActionIsGaugeInvariant` applies a random α and
asserts the total action is unchanged to round-off.

## Local Metropolis update

Updating one link `(y, μ)` by `θ_μ(y) → θ'` affects only the
`2 · (Dim − 1)` plaquettes containing it: one **positive plaquette**
`(y; μ, ν)` and one **negative plaquette** `(y − ê_ν; μ, ν)` per ν ≠ μ.

Collecting the other-link contributions into the complex **staple**

```
A_μ(y) = Σ_{ν ≠ μ} [ e^{i φ_+(ν)} + e^{−i φ_−(ν)} ]

  φ_+(ν) = θ_ν(y + ê_μ) − θ_μ(y + ê_ν) − θ_ν(y)
  φ_−(ν) = θ_μ(y − ê_ν) + θ_ν(y − ê_ν + ê_μ) − θ_ν(y − ê_ν)
```

the sum of plaquette actions touching the link reduces to

```
S_local(θ) = const − β · Re[ e^{iθ} · A_μ(y) ]
```

so the change under `θ → θ'` is exactly

```
ΔS = β · Re[(e^{iθ} − e^{iθ'}) · A_μ(y)]
   = β · [(cos θ − cos θ') · A_re + (sin θ' − sin θ) · A_im].
```

This is what `U1Model::delta_action(...)` computes; `U12D.DeltaSMatchesActionDifference`
verifies it matches the literal `totalAction(after) − totalAction(before)` to
machine precision.

## Color partition for parallel updates

Two link updates are independent iff they share no plaquette. Two link
updates `(y₁, μ)` and `(y₂, μ)` of the **same direction** at sites of the
same parity never share a plaquette — but two link updates of **different
directions** sharing a corner do. The safe coloring is therefore

```
color(y, μ) = parity(y) · Dim + μ   ∈   {0, …, 2·Dim − 1}.
```

For Dim = 2 this is 4 colors. On the CPU we sweep colors sequentially; the
correctness of single-thread Metropolis doesn't depend on it, but the GPU
port will iterate `numColors` dispatches and exploit the parallelism within
each.

## 2D closed-form benchmark — Bessel-ratio

The 2D partition function with no boundaries factorizes link by link
(equivalently: the dual variables are trivial in 2D). The result is the
exact one-plaquette expectation

```
⟨cos θ_□⟩ = I_1(β) / I_0(β)
```

and the Wilson-loop area law

```
⟨W(R, T)⟩ = (I_1(β) / I_0(β))^{R · T}.
```

There are no finite-volume corrections. The CI tests assert agreement to
better than 5 % on a small L = 12 lattice; the standalone driver `--model u1`
reproduces both `⟨cos θ_□⟩` and `⟨W(2, 2)⟩` to ≲ 0.5 % accuracy on L = 16
across β ∈ [0.5, 5.0].

The static-quark string tension is `σ(β) = − ln(I_1(β) / I_0(β))`. For
β → ∞ this approaches `σ → 1/(2β)` (the continuum limit); for β → 0 the
plaquettes decorrelate, `I_1/I_0 → 0`, and σ → ∞ (confinement is the
default).

## When heat-bath replaces Metropolis

For U(1) the single-link conditional distribution at fixed staple is

```
P(θ | A) ∝ exp(β |A| cos(θ − arg A))
```

— a **von Mises distribution**. It can be sampled with 100 % acceptance
using the Best–Fisher 1979 algorithm. Heat-bath dominates Metropolis at
strong coupling (small β), where Metropolis acceptance struggles even
with a tuned step size (in our β = 0.5 driver run the auto-tuner hits the
step-size cap because the action is too flat for any local proposal to be
preferred). Folding heat-bath in here is also the right preparation for
non-Abelian SU(2) at Phase 4, where the Cabibbo–Marinari heat-bath uses the
exact same conditional structure.
